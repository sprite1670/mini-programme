# 我的小程序

原生微信小程序起步项目：首页互动、我的页面、版本信息和好友分享。无需登录、数据库或自建服务器。当前版本 0.1.0，页面内容可继续通过手机 Codex 修改。

## 当前可用范围

- 应用目录：`miniprogram/`；微信开发者工具导入仓库根目录。
- `project.config.json` 中的 `touristappid` 是本地占位符，不代表已绑定账号。获得真实 AppID 后可以替换它；AppID 不是密钥。CI 使用 `WX_APPID`，无需把私钥写入项目。
- `npm run validate` 检查结构和 JavaScript，并运行页面行为测试。它不等于微信编译、体验版可访问或真机验证。
- 分享按钮调用微信原生分享能力。预览版、体验版和正式版的访问权限由微信决定，不能绕过体验成员限制。

## 云端开发

使用现有检出目录；每个 Codex 云任务已隔离，不需要额外 Git worktree。

```sh
cd /workspace/mini-programme
npm ci
npm run validate
```

需要 Node.js 22 或 24（CI 固定 Node.js 22）。没有常驻服务或 localhost 网页；这是微信小程序，不是浏览器应用。首次创建项目已生成 `package-lock.json`，后续安装使用 `npm ci`。小程序目录之外的工具和依赖不需要通过开发者工具“构建 npm”。

## 首次绑定微信账号（管理员一次性操作）

1. 微信公众平台 → 开发管理 → 开发设置，确认 AppID、代码上传能力并生成小程序代码上传私钥。后台名称可能随微信版本调整。
2. GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret：
   - `WX_APPID`：真实的小程序 AppID。
   - `WX_PRIVATE_KEY`：完整私钥文件内容，包含 PEM 首尾行和真实换行。不要填写文件名，不要把内容发到 Codex 对话里。
3. 微信后台配置上传 IP 白名单。GitHub 托管 runner 的出口 IP 会变化，不能假设默认 `ubuntu-latest` 每次都能通过白名单。推荐使用有固定公网出口的 runner，并在微信后台仅允许该出口 IP。可以添加仓库 Actions 变量 `WX_RUNNER`，值为你的固定出口 runner 标签，例如 `wechat-fixed-egress`。该 runner 必须预装 Git、可运行 Node.js 22，并可访问 npm、GitHub Actions 和微信上传服务。不要为方便上传盲目放开白名单。
4. 如果使用默认 GitHub runner，必须先确认账号允许的上传网络方案；没有合适白名单配置时，微信上传尚不可用。上传权限、服务类目和账号实际后台能力也必须符合微信要求。
5. 在微信后台成员管理中添加自己的微信为开发者/体验者，并添加要邀请的体验成员。

私钥只在手动微信任务的上传步骤注入，写入临时目录后删除。预览码存为 GitHub artifact，保留一天。不要提交任何 `.key`、`.pem`、`.env` 或预览码。

## 以后只用手机怎么操作

1. 在手机 Codex 中选择本仓库，描述功能；修改完成后检查 `npm run validate` 结果并提交、推送 GitHub。
2. 打开手机浏览器中的 GitHub 仓库（必要时切换桌面站点）→ Actions。确认 `Check` 通过。
3. 打开 `WeChat` → Run workflow，选择 `main`、版本号 `x.y.z` 和更新说明：
   - `preview`：生成临时预览码，可在该次任务的 `wechat-preview` 附件下载；能否在同一手机识别并打开取决于微信客户端和预览权限，需首次实测。
   - `upload`：上传开发版；随后在微信公众平台版本管理中把对应开发版选为体验版。这一步不由脚本自动执行。
4. 手机微信从小程序的体验版入口打开验证；要邀请好友，先在后台添加体验成员，再分享体验版。
5. 给普通好友直接使用，需要后台提交审核并正式发布。此项目不自动审核或发布。

手机适合验证交互、反馈问题和继续让 Codex 修改；完整模拟器、断点调试仍需电脑微信开发者工具。第一次绑定和体验版入口配置，手机网页若操作受限，可能需要电脑完成。

## 本地微信工具验证

导入仓库根目录并填写真实 AppID，检查：首页计数可累加、底部标签和“了解”按钮可切换页面、“我的”页显示版本、关于弹窗正常、分享卡片路径为首页。分享和好友访问需要微信真机及相应成员权限验证。

## 命令与发布限制

```sh
npm run check       # 项目文件与 JS 语法
npm test            # 页面逻辑测试，模拟 wx API
npm run validate    # 上述全部检查
npm run wx:preview  # 需要安全注入微信凭据、权限和网络白名单
npm run wx:upload   # 同上，只上传开发版
```

本地运行微信命令时同样不要把密钥放进命令参数、终端历史或版本库。`WX_VERSION` 默认 `0.1.0`，`WX_DESCRIPTION` 为更新说明，`WX_ROBOT` 默认为 1（支持 1–30）。

当前没有用户数据采集、微信登录或服务端请求。后续增加这些功能时，应同步配置合法域名、隐私声明和适合个人主体的服务类目。
