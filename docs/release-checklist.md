# 发布前与权限检查清单

第一阶段不建议正式用于敏感资料；下列未完成项不得标记通过。

- [ ] 仓库可见性确认为Private，密钥仅保存在安全设置。
- [ ] 真实AppID/云环境匹配，测试与生产环境分离。
- [ ] users/families/invitations已创建，实际云函数部署成功。
- [ ] 所有业务集合客户端读写全禁，云存储客户端全禁，已真机验证。
- [ ] auth/family仅小程序可信上下文调用，无匿名HTTP入口。
- [ ] 两个以上不同微信账号创建/加入/移除/退出同步通过。
- [ ] 真实云数据库并发邀请码核销与一人一家庭不变式通过。
- [ ] 越权和跨家庭读取/写入、邀请码重放/过期/撤销测试通过。
- [ ] 日程与任务（第二阶段）UTC/夏令时、负责人权限、逾期提示通过。
- [ ] 账本（第三阶段）CNY/NZD整数金额、分类/月汇总、定点汇率通过。
- [ ] 私有资料、短期受控文件访问、文件删除权限与成员移除后访问边界通过。
- [ ] 动态不公开，照片受控，只有作者删除。
- [ ] 数据导出、账号删除、回收站/恢复与物理删除策略（第四阶段）完成并验证。
- [ ] 隐私指引、账号删除联系方式、个人主体服务类目与平台审核要求匹配。
- [ ] 日志无OpenID/邀请码/附件链接/私钥，错误仅安全分类。
- [ ] 320–414px设备与安全区域、44px按钮、错误/空/加载/成功状态验证。
- [ ] 微信官方编译、预览、体验成员访问通过，GitHub检查通过。
- [ ] 检查微信云平台费用、备份和恢复操作，不依赖永久免费/无限制后台推送。
- [ ] 管理员明确选择版本，手动提交审核与发布；上传成功不等于已发布。
